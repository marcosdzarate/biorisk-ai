# BiodivRisk-Onto documentation

This directory contains the documentation and machine-readable distributions of **BiodivRisk-Onto v0.3.0**, an ontology for representing biodiversity-risk assessment concepts, framework correspondences, semantic ambiguities, and evidence used in corporate nature-risk analysis.

## Documentation

- [Browse the published ontology documentation](https://marcosdzarate.github.io/biorisk-ai/)
- [View the documentation source](index.html)
- [Review the competency questions and SPARQL queries](competency-questions.md)

## Ontology distributions

- [RDF/XML](ontology.owl)
- [Turtle](ontology.ttl)
- [JSON-LD](ontology.jsonld)
- [N-Triples](ontology.nt)
- [WebVOWL visualization](https://marcosdzarate.github.io/biorisk-ai/webvowl/)

The canonical ontology source and reproducible documentation configuration are available in the parent [ontology directory](../).
